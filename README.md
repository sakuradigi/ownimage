# ⚡️ GPT Image 2.5 視覺創作與圖像修復工作台

專為圖卡設計、市政文宣、政治攻防與社群影像打造的輕量化 Web 工作台。完全支援 OpenAI 最新發布的 **GPT Image 2.5** 系列模型，整合了 **Fabric.js 互動式畫布**、**全圖自適應預覽 (Fit-to-View)**、**塗抹遮罩與上一步 (Undo) 局部修圖**、**參考圖片以圖生圖 (Image-to-Image)**、**三大專業圖卡深度 Prompt 模式**、**本機永久資料庫 (IndexedDB 儲存)**、**淺色/深色主題切換** 與 **本機安全金鑰機制**。

---

## ✨ 核心特色

1. **支援 OpenAI GPT Image 2.5 旗艦雙模型**：
   * ⚡️ **`gpt-image-2.5-flare`**：小模型、預設模型，官方稱延遲約為 GPT Image 2 的一半，適合日常出圖。
   * 🌟 **`gpt-image-2.5-sunburst`**：旗艦模型，畫質較高、速度較慢，**修圖建議改選此模型**。
   * 🪟 **原生透明背景支援**：支援輸出乾淨去背的透明背景（Transparent PNG/WebP）。
   * 📐 **多元解析度與 16 倍數自動校準**：支援 `1920x1088` (1080p FHD 規格)、`1536x864` (快速 16:9 簡報)、`3840x2160` (4K 旗艦)、`1024x1024` (1:1 正方) 與 `864x1536` (9:16 直式)；內建尺寸校準（16 倍數、最長邊 ≤ 3840、比例 1:3～3:1、總像素 655,360～8,294,400），本機上傳的任意尺寸照片修圖前會自動縮放到合法尺寸，完成後還原。
2. **三大專業圖卡深度 Prompt 模式（一鍵自動套用 ＆ 結構式版型向下開展）**：
   * 🏛️ **官方高質感施政圖卡 (`policy-infographics`)**：
     * 自動套用 16:9 比例與大師級架構（半屏實景融圖、科技深藍/翡翠綠漸層、白金雙色標題、金黃數據放大高亮、無雜質零浮水印）。
     * 提供「重大建設半屏融圖」、「全屏大景空拍」、「數據驅動六都評比」等細分版型。
   * ⚔️ **政治攻防與事實澄清 (`political-meme-generator`)**：
     * 自動套用 1:1 黃金比例、新聞截圖鐵證打臉、人物尷尬嘴角抽搐表情 (Awkward Flustered)、關鍵字紅字強調、2-1 雙層卡片佈局與【源頭打臉】鋼印。
     * 提供「新聞鐵證打臉卡」、「現場真實照片壓字」、「左右雙標對比」等細分版型。
   * 🗳️ **2026 選戰專用圖卡 (`選戰專用圖卡.md`)**：
     * 自動套用 16:9 比例與瑞士風排版，具備字體層級雙混搭原則（明體鋪陳＋超粗黑體核心金句）、雙色亮點對比（白底＋亮金黃高光）、非對稱留白與角落落款。
     * 提供三大核心戰術模組：
       1. **【模組 1】純文字哲思／政策金句型 (Editorial Quote)**：文人思考、白金雙色金句、極簡幾何菱形中軸。
       2. **【模組 2】熱血現場／造勢滿版壓字型 (Action Rally)**：萬人造勢紀實、下緣 35% 漸層融圖、平行句雙節奏對比。
       3. **【模組 3】雙首長合體／高階背書形象型 (Executive Endorsement)**：雙首長定裝大師級構圖、對話框強力背書。
3. **參考素材「以圖生圖」 (Image-to-Image / 1～5 張多圖融合 ＆ 雙人合體)**：
   * **放寬支援 1～5 張素材多選與拖曳**：一次上傳兩位政治人物照片、LOGO、造勢舞台或風格素材。
   * **雙人/多人物卡片式管理**：清楚呈現【素材 1】、【素材 2】等順序標籤、縮圖、解析度、個別移除與清空。
   * **一鍵「帶入雙人提示」**：自動在 Prompt 插入角色分配指引（如：`【素材 1】為候選人，【素材 2】為站台貴賓，兩人並肩站立...`），大幅提升 AI 理解度。
   * **雙重融合架構（原生多圖 ＆ 雙人並排合拼圖）**：
     * **原生多圖傳送 (推薦)**：以 `image[]` 欄位同時送出多張素材至 edits 端點。
     * **雙人並排合拼圖**：自動將多張照片在記憶體畫布中以並排格點拼接並打上【素材 N】鋼印，作為原生多圖不被接受時的備援（只在圖片類 400 錯誤時自動降級，不會因額度或審查錯誤重複扣費）。
4. **本機永久圖庫 (IndexedDB) ‧ 重新整理絕不消失**：
   * 內建瀏覽器原生離線資料庫（容量可達數 GB）。
   * 每張生成的圖片與修圖成品皆自動轉為高畫質資料儲存於電腦中，**即便重新整理網頁、關閉瀏覽器或重開機，歷史圖片完全保留**！
   * 歷史圖庫支援隨時重新載入畫布二次編輯、單張原圖下載、或單獨刪除。
   * 支援「**生成後自動下載備份至電腦 (Downloads)**」開關，雙重保險！
5. **全圖最適預覽與自由縮放 (Zoom & Fit-to-View)**：
   * 不論是 9:16 直式早安圖/文宣、16:9 寬螢幕圖或 1:1 正方圖，皆可點擊右上角 **「最適全圖」** 完整呈現，絕不裁切任何角落！
   * 支援 **[+] 放大**、**[-] 縮小**、**[100%] 原寸** 與 **Ctrl/Cmd + 滾輪縮放**。
6. **紅框／筆刷局部修圖 (Inpainting) ＋ 框外像素鎖定**：
   * GPT Image 的遮罩只是「提示」，模型實際上會整張重算。工作台在收到結果後，會把紅框外區域以原圖像素貼回（邊緣柔化），勾選「鎖定紅框外」即可確保框外 100% 不變。
   * 切換至「局部遮罩修圖」，使用紅色筆刷塗抹想要修改的局部。
   * **畫錯不必重來**：支援工具列 **「上一步 (Undo)」**、**「下一步 (Redo)」**，或直接按鍵盤快捷鍵 `Cmd+Z` / `Ctrl+Z` 逐筆撤銷！
7. **淺色 / 深色模式 (Light & Dark Mode)**：
   * 點擊頂部月亮/太陽圖標，隨時在清爽明亮的「淺色模式」與沉浸高質感的「深色模式」間無縫切換。
8. **暗房背景調色系統 (Digital Darkroom - 灰階 ＆ RGB)**：
   * **單軸灰階明暗滑桿**：0%~100% 亮度快速滑動，秒速找到最順眼的專業灰色。
   * **RGB 色溫微調滑桿**：微調冷暖色調（冷調藍灰、暖調炭灰）。
   * **5 大經典暗房預設**：提供影視炭黑 (`#18181b`)、PS/LR 深灰 (`#2e2e2e`)、18% 攝影中性灰 (`#777777`)、冷灰 (`#1e293b`) 與極致純黑 (`#000000`) 一鍵切換。
   * **作用範圍與本機記憶**：可切換「僅中央畫布襯底 (推薦)」或「全網頁暗房模式」，設定自動保存在瀏覽器中。
9. **本機安全儲存，零資安疑慮**：
   * API Key 僅儲存在您個人瀏覽器的 `localStorage` 中，程式碼無任何寫死 Key，可安全上傳至 Git 與部署到 GitHub Pages。

## 🛠️ 修圖怎麼下指令最有效（v2 修圖引擎）

修圖時，工作台**只送出「這次要改什麼」**，並自動附加保留規則（其餘構圖、人臉、文字一律不動），不會再把整份原始生圖 Prompt 重送。

* **一次只改一件事**：「把主標題改成『高雄市』」比「標題改字、背景變亮、人物往左」一次三件事穩定得多。
* **要出現的文字用引號包起來**：「」『』“” 內的字會被要求逐字呈現。
* **只想改某一塊，先拉紅框**：搭配「鎖定紅框外」，框外保證不變。
* **文字要大改或重排版**：不要框選，直接用全圖修改，或回「全新生圖」改 Prompt 重生。
* **修圖建議選 `gpt-image-2.5-sunburst`**，畫質可選 High / XHigh。
* 每一次修改都會存入歷史圖庫，並記錄原始 Prompt 與修改歷程；不滿意可直接點回上一版。

## ⚠️ 已知限制

* API Key 存在瀏覽器 `localStorage`，並由瀏覽器直接呼叫 OpenAI。請只在個人電腦使用，並在 OpenAI 後台為此 Key 設定用量上限。
* 模型重算整張圖時，紅框邊緣可能有輕微接縫；可稍微把紅框拉大一點。
* `run_gui.py` 在 OpenAI 失敗時會改送第三方 Pollinations 服務，Prompt 內容會外送，處理敏感文案時請注意。
