# ⚡️ GPT Image 2.5 視覺創作與圖像修復工作台

專為圖卡設計、視覺創作、文宣企劃與社群影像打造的輕量化 Web 工作台。完全支援 OpenAI 最新發布的 **GPT Image 2.5** 系列模型，整合了 **Fabric.js 互動式畫布**、**全圖自適應預覽 (Fit-to-View)**、**塗抹遮罩與上一步 (Undo) 局部修圖**、**文字圖層排版**、**本機永久資料庫 (IndexedDB 儲存)**、**淺色/深色主題切換** 與 **本機安全金鑰機制**。

---

## ✨ 核心特色

1. **支援 OpenAI GPT Image 2.5 旗艦雙模型**：
   * ⚡️ **`gpt-image-2.5-flare`**：推薦日常出圖模型，速度提升 50%，出圖迅捷流暢。
   * 🌟 **`gpt-image-2.5-sunburst`**：旗艦高精細模型，特別擅長精細畫質與微調修圖，能極佳維持主體一致性。
   * 🪟 **原生透明背景支援**：支援輸出乾淨去背的透明背景（Transparent PNG/WebP）。
2. **本機永久圖庫 (IndexedDB) ‧ 重新整理絕不消失**：
   * 內建瀏覽器原生離線資料庫（容量可達數 GB）。
   * 每張生成的圖片與修圖成品皆自動轉為高畫質資料儲存於電腦中，**即便重新整理網頁、關閉瀏覽器或重開機，歷史圖片完全保留**！
   * 歷史圖庫支援隨時重新載入畫布二次編輯、單張原圖下載、或手動清理。
   * 支援「**生成後自動下載備份至電腦 (Downloads)**」開關，雙重保險！
3. **全圖最適預覽與自由縮放 (Zoom & Fit-to-View)**：
   * 不論是 9:16 直式早安圖/文宣、16:9 寬螢幕圖或 1:1 正方圖，皆可點擊右上角 **「最適全圖」** 完整呈現，絕不裁切任何角落！
   * 支援 **[+] 放大**、**[-] 縮小**、**[100%] 原寸** 與 **Ctrl/Cmd + 滾輪縮放**，方便精細微調。
4. **支援「上一步 (Undo)」的局部修圖 (Inpainting)**：
   * 切換至「局部遮罩修圖」，使用紅色筆刷塗抹想要修改的局部。
   * **畫錯不必重來**：支援工具列 **「上一步 (Undo)」**、**「下一步 (Redo)」**，或直接按鍵盤快捷鍵 `Cmd+Z` / `Ctrl+Z` 逐筆撤銷！
   * 自動合成 OpenAI 規格的透明遮罩並發送至 `/v1/images/edits` 端點精準局部重繪。
5. **淺色 / 深色模式 (Light & Dark Mode)**：
   * 點擊頂部月亮/太陽圖標，隨時在清爽明亮的「淺色模式」與沉浸高質感的「深色模式」間無縫切換，並自動記憶您的偏好。
6. **文字圖層與外框描邊排版**：
   * 一鍵加入頂部/底部文字，支援粗體黑白描邊效果（Impact / Heavy Bold），確保文字在任何光影背景下都能清晰立體。
7. **本機安全儲存，零資安疑慮**：
   * API Key 僅儲存在您個人瀏覽器的 `localStorage` 中，程式碼無任何寫死 Key，可安全上傳至 Git 與部署到 GitHub Pages。

## 🚀 快速開始

### 方式 A：線上使用（GitHub Pages）
直接在瀏覽器打開您的線上工作台：
👉 **https://sakuradigi.github.io/ownimage/**
點擊右上角「設定 API Key」即可開始創作！

### 方式 B：本機直接雙擊開啟
1. 在 Mac Finder 中，直接對著 `index.html` 點擊滑鼠右鍵，選擇使用 **Google Chrome** 或 **Safari** 開啟。
2. 點擊右上角 **「設定 API Key」**，貼上您的 OpenAI API Key。
