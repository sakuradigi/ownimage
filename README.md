# ⚡️ GPT Image 2.5 視覺創作與圖像修復工作台

專為圖卡設計、視覺創作、文宣企劃與社群影像打造的輕量化 Web 工作台。完全支援 OpenAI 最新發布的 **GPT Image 2.5** 系列模型，整合了 **Fabric.js 互動式畫布**、**全圖自適應預覽 (Fit-to-View)**、**塗抹遮罩與上一步 (Undo) 局部修圖**、**文字圖層排版**、**淺色/深色主題切換** 與 **本機安全金鑰機制**。

---

## ✨ 核心特色

1. **支援 OpenAI GPT Image 2.5 旗艦雙模型**：
   * ⚡️ **`gpt-image-2.5-flare`**：推薦出圖模型，速度提升 50%，日常創作迅捷流暢。
   * 🌟 **`gpt-image-2.5-sunburst`**：旗艦高精細模型，特別擅長精細畫質與微調修圖，能極佳維持主體一致性。
   * 🪟 **原生透明背景支援**：支援輸出乾淨去背的透明背景（Transparent PNG/WebP）。
2. **全圖最適預覽與自由縮放 (Zoom & Fit-to-View)**：
   * 不論是 9:16 直式早安圖/文宣、16:9 寬螢幕圖或 1:1 正方圖，皆可點擊右上角 **「最適全圖」** 完整呈現，絕不裁切任何角落！
   * 支援 **[+] 放大**、**[-] 縮小**、**[100%] 原寸** 與 **Ctrl/Cmd + 滾輪縮放**，方便精細微調。
3. **支援「上一步 (Undo)」的局部修圖 (Inpainting)**：
   * 切換至「局部遮罩修圖」，使用紅色筆刷塗抹想要修改的局部。
   * **畫錯不必重來**：支援工具列 **「上一步 (Undo)」**、**「下一步 (Redo)」**，或直接按鍵盤快捷鍵 `Cmd+Z` / `Ctrl+Z` 逐筆撤銷！
   * 自動合成 OpenAI 規格的透明遮罩並發送至 `/v1/images/edits` 端點精準局部重繪。
4. **淺色 / 深色模式 (Light & Dark Mode)**：
   * 點擊頂部月亮/太陽圖標，隨時在清爽明亮的「淺色模式」與沉浸高質感的「深色模式」間無縫切換，並自動記憶您的偏好。
5. **文字圖層與外框描邊排版**：
   * 一鍵加入頂部/底部文字，支援粗體黑白描邊效果（Impact / Heavy Bold），確保文字在任何光影背景下都能清晰立體。
6. **本機安全儲存，零資安疑慮**：
   * API Key 僅儲存在您個人瀏覽器的 `localStorage` 中，程式碼無任何寫死 Key，可安全上傳至 Git 與部署到 GitHub Pages。

## 🚀 快速開始

### 方式 A：本機直接雙擊開啟（最快）
1. 在 Mac Finder 中，直接對著 `index.html` 點擊滑鼠右鍵，選擇使用 **Google Chrome** 或 **Safari** 開啟。
2. （或在終端機啟動本地簡易伺服器）：
   ```bash
   python3 -m http.server 8000
   ```
   然後在瀏覽器打開 `http://localhost:8000`。
3. 點擊右上角 **「設定 API Key」**，貼上您的 OpenAI API Key（只需輸入一次，瀏覽器會自動記住）。

---

### 方式 B：部署至 GitHub Pages（隨時隨地開啟）

您只要把本專案推送到 GitHub，就能免費獲得一個專屬的雲端 Web 應用：

1. **推送到 GitHub**：
   ```bash
   git init
   git add index.html README.md .gitignore
   git commit -m "feat: Launch GPT Image 2.5 Visual Studio"
   git branch -M main
   git remote add origin https://github.com/您的帳號/您的專案名稱.git
   git push -u origin main
   ```

2. **啟用 GitHub Pages**：
   * 進入 GitHub Repo 的 **Settings** ➜ **Pages**。
   * 在 **Branch** 選擇 `main` 分支與 `/ (root)`，點擊 **Save**。
   * 約 1 分鐘後即可開啟專屬網址。

## 🎨 操作指引

### 1. 全新生圖
* 選擇模型（預設為極速 `gpt-image-2.5-flare`）。
* 選擇尺寸（如 9:16 直式 864x1536）。
* 輸入提示詞或點選快捷靈感標籤（早安綠意、文宣圖卡、新聞現場等）。
* 點擊「立即生成圖片」，生成完成後會自動進行最適全圖縮放，一覽無遺！

### 2. 局部修圖 (Inpainting)
* 切換左側至 **「局部遮罩修圖」** 分頁。
* 在畫布上塗抹想要修改的局部區塊（畫錯隨時按 `Cmd+Z` 撤銷）。
* 在 Prompt 描述塗抹區塊希望換成什麼（例如：「將綠葉換成盛開的向日葵」）。
* 點擊「開始局部修圖」，AI 將維持其他背景不變，精準替換塗抹區塊！

### 3. 排版與輸出
* 點擊 **「+頂部文字」** 或 **「+底部文字」** 調整字體大小、描邊與位置。
* 點擊右上角 **「下載完成圖」**（保持原生高解析度輸出）或 **「複製圖片」** 直接貼上發送。
