# ⚡️ GPT Image 2.5 視覺創作與圖像修復工作台

專為圖卡設計、市政文宣、政治攻防與社群影像打造的輕量化 Web 工作台。完全支援 OpenAI 最新發布的 **GPT Image 2.5** 系列模型，整合了 **Fabric.js 互動式畫布**、**全圖自適應預覽 (Fit-to-View)**、**多張候選比稿托盤 (1~4 張控管)**、**塗抹遮罩與上一步 (Undo) 局部修圖**、**參考圖片以圖生圖 (Image-to-Image / 剪貼簿 Ctrl+V 貼上)**、**三大專業圖卡深度 Prompt 模式**、**本機永久資料庫 (IndexedDB 儲存)**、**淺色/深色主題切換** 與 **本機安全金鑰機制**。

---

## ✨ 核心特色

1. **支援 OpenAI GPT Image 2.5 旗艦雙模型**：
   * ⚡️ **`gpt-image-2.5-flare`**：小模型、預設模型，延遲極低、反應迅速，適合日常出圖與快速嘗試。
   * 🌟 **`gpt-image-2.5-sunburst`**：旗艦模型，細節紋理豐富、文字渲染更精確，**修圖建議改選此模型**。
   * 🪟 **原生透明背景支援**：支援輸出純 Alpha 透明通道（Transparent PNG/WebP），內建自動防偽棋盤格約束，杜絕 AI 畫出灰白格子。
   * 📐 **多元解析度與 16 倍數自動校準**：支援 `1920x1088` (1080p FHD 規格)、`1536x864` (快速 16:9 簡報)、`3840x2160` (4K 旗艦)、`1024x1024` (1:1 正方) 與 `864x1536` (9:16 直式)；內建尺寸校準（16 倍數、最長邊 ≤ 3840、比例 1:3～3:1、總像素 655,360～8,294,400），本機上傳的任意尺寸照片修圖前會自動縮放到合法尺寸，完成後還原。
2. **生成張數可控 (1~4 張) ＆ 智能建議模式 ＆ 候選比稿托盤**：
   * 🔢 **靈活張數切換**：可自由選擇一次生成 **1 張**、**2 張**、**3 張**、**4 張**，或選擇 **「建議 (auto)」** 模式。
   * 💡 **OpenAI 建議模式 (auto)**：依畫質與解析度智能決定張數——草稿 (Low) 產出 3 張快速比稿、標準 (Medium/Auto) 產出 2 張對照、精細 (High/XHigh) 或 4K 解析度專注產出 1 張。
   * 🖼️ **多張候選托盤 (Results Tray)**：一次生成多張時自動展開比稿托盤，點選縮圖可無縫載入主畫布二次編輯、支援個別下載或「一鍵全部下載」。
   * 💾 **全數入庫不遺漏**：生成的多張候選圖全部自動保存至本機 IndexedDB 資料庫，即使重新整理或日後查看都能隨時翻閱。
3. **強化型連線層（逾時防護、自動重試、隨時取消、中文化錯誤）**：
   * ⏱️ **逾時與取消控制**：高畫質或網路波動時提供最長 6 分鐘逾時防護，隨時可點擊「取消本次請求」立即中斷。
   * 🔁 **智能指數退避重試**：遇到網路瞬斷或 429/500/503 暫態錯誤時自動等待並重試，避免手動重整。
   * 🛡️ **友善錯誤診斷**：針對額度不足、API Key 失效、敏感內容審查阻擋提供直白中文指引。
4. **快捷鍵與工作流流暢度**：
   * ⌨️ **`Ctrl/⌘ + Enter`**：在左側提示詞框直接快速送出生成。
   * 💬 **補充修正對話框**：支援 `Shift + Enter` 跳行換行、`Enter` 直接送出修正。
   * 📋 **剪貼簿直接貼圖 (`Ctrl/⌘ + V`)**：複製網路或本機圖片後直接在頁面上按貼上，免去手動儲存再上傳檔案的繁瑣流程。
   * ↔️ **左側面板一鍵折疊**：點擊折疊按鈕收整工具列，將工作空間 100% 留給畫布預覽。
5. **三大專業圖卡深度 Prompt 模式（一鍵自動套用 ＆ 結構式版型向下開展）**：
   * 🏛️ **官方高質感施政圖卡 (`policy-infographics`)**：
     * 自動套用 16:9 比例與大師級架構（半屏實景融圖、科技深藍/翡翠綠漸層、白金雙色標題、金黃數據放大高亮、無雜質零浮水印）。
     * 提供「重大建設半屏融圖」、「全屏大景空拍」、「數據驅動六都評比」等細分版型。
   * ⚔️ **政治攻防與事實澄清 (`political-meme-generator`)**：
     * 自動套用 1:1 黃金比例、新聞截圖鐵證打臉、人物尷尬嘴角抽搐表情 (Awkward Flustered)、關鍵字紅字強調、2-1 雙層卡片佈局與【源頭打臉】鋼印。
     * 提供「新聞鐵證打臉卡」、「現場真實照片壓字」、「左右雙標對比」等細分版型。
   * 🗳️ **2026 選戰專用圖卡 (`選戰專用圖卡.md`)**：
     * 自動套用 16:9 比例與瑞士風排版，具備字體層級雙混搭原則（明體鋪陳＋超粗黑體核心金句）、雙色亮點對比（白底＋亮金黃高光）、非對稱留白與角落落款。
     * 提供三大核心戰術模組：純文字哲思／政策金句型、熱血現場／造勢滿版壓字型、雙首長合體／高階背書形象型。
6. **參考素材「以圖生圖」 (Image-to-Image / 1～5 張多圖融合 ＆ 雙人合體)**：
   * **放寬支援 1～5 張素材多選與拖曳**：一次上傳兩位政治人物照片、LOGO、造勢舞台或風格素材。
   * **雙人/多人物卡片式管理**：清楚呈現【素材 1】、【素材 2】等順序標籤、縮圖、解析度、個別移除與清空。
   * **一鍵「帶入雙人提示」**：自動在 Prompt 插入角色分配指引，大幅提升 AI 理解度。
   * **雙重融合架構（原生多圖 ＆ 雙人並排合拼圖備援）**：原生多圖遇特定格式限制時自動降級合拼圖送出。
7. **本機永久圖庫 (IndexedDB) ‧ 重新整理絕不消失**：
   * 內建瀏覽器原生離線資料庫（容量可達數 GB）。
   * 每張生成的圖片與修圖成品皆自動轉為高畫質資料儲存於電腦中，**即便重新整理網頁、關閉瀏覽器或重開機，歷史圖片完全保留**！
   * 支援「**生成後自動下載備份至電腦 (Downloads)**」開關。
8. **全圖最適預覽與自由縮放 (Zoom & Fit-to-View)**：
   * 不論是 9:16 直式早安圖/文宣、16:9 寬螢幕圖或 1:1 正方圖，皆可點擊右上角 **「最適全圖」** 完整呈現，絕不裁切任何角落！
   * 支援 **[+] 放大**、**[-] 縮小**、**[100%] 原寸** 與 **Ctrl/Cmd + 滾輪縮放**。
9. **紅框／筆刷局部修圖 (Inpainting) ＋ 框外像素鎖定**：
   * GPT Image 的遮罩只是「提示」，模型實際上會整張重算。工作台在收到結果後，會把紅框外區域以原圖像素貼回（邊緣柔化），勾選「鎖定紅框外」即可確保框外 100% 不變。
   * 支援工具列 **「上一步 (Undo)」**、**「下一步 (Redo)」**，或直接按快捷鍵 `Cmd+Z` / `Ctrl+Z` 逐筆撤銷。
10. **暗房背景調色系統 (Digital Darkroom - 灰階 ＆ RGB)**：
    * 支援 0%~100% 單軸灰階明暗與冷暖色溫滑桿，具備 5 大經典暗房預設（影視炭黑、PS/LR 深灰、18% 中性灰、冷灰、極致純黑）。

## 🛠️ 修圖怎麼下指令最有效（v2 修圖引擎）

修圖時，工作台**只送出「這次要改什麼」**，並自動附加保留規則（其餘構圖、人臉、文字一律不動），不會再把整份原始生圖 Prompt 重送。

* **一次只改一件事**：「把主標題改成『高雄市』」比「標題改字、背景變亮、人物往左」一次三件事穩定得多。
* **要出現的文字用引號包起來**：「」『』“” 內的字會被要求逐字呈現。
* **只想改某一塊，先拉紅框**：搭配「鎖定紅框外」，框外保證不變。
* **文字要大改或重排版**：不要框選，直接用全圖修改，或回「全新生圖」改 Prompt 重生。
* **修圖建議選 `gpt-image-2.5-sunburst`**，畫質可選 High / XHigh。
* 每一次修改都會存入歷史圖庫，並記錄原始 Prompt 與修改歷程；不滿意可直接點回上一版。

## ⚠️ 已知限制

* API Key 存在瀏覽器 `localStorage`，並由瀏覽器直接呼叫 OpenAI。請只在個人電腦使用，並在 OpenAI 後台為此 Key 設定用量上限。
* 模型重算整張圖時，紅框邊緣可能有輕微接縫；可稍微把紅框拉大一點。
* `run_gui.py` 在 OpenAI 失敗時會改送第三方 Pollinations 服務，Prompt 內容會外送，處理敏感文案時請注意。
